# HMCL But Without No 7017 PR

This repo provides simplest patch to revert changes made in [HMCL-Dev/HMCL#7017](https://github.com/HMCL-Dev/HMCL/pull/7017).

**LIMITATION!** The compiled EXE does not allow you to add new Microsoft accounts because we cannot disclose HMCL’s Microsoft OAuth client secret.
